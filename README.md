# Cookie Consent for EmDash

A cookie banner done properly: accept, reject or choose by category, nothing runs before consent, Google Consent Mode v2, and a record of every choice.

- **Three equal choices**: Accept all, Reject all, Manage preferences.
- **Four categories**: Necessary, Preferences, Analytics, Marketing, each with the cookies it holds.
- **Real blocking**: tagged scripts and embeds wait for consent; well-known trackers are held automatically.
- **Google Consent Mode v2** signals, denied by default, updated on choice.
- **Proof of consent**: consent ID, time, choice, categories, version. Searchable. No personal data.
- **Cookie discovery**: new cookie names seen on the site show up for one-click categorising.
- **All yours**: layout, position, colours, wording, region rule, expiry.

One-time setup: download the script from the Setup tab, put it in `public/`, and load it as the first script in your layout's head. Everything else is managed in the admin.
